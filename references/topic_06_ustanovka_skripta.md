### Установка скрипта на сервер

Установка скрипта на сервер проходит в автоматическом режиме и не должна вызывать особых проблем, но вам необходимо выполнить некоторые действия по настройке прав доступа на папки.

- Для начала скопируйте все файлы из папки `/upload/` из архива дистрибутива на ваш сервер. Мы рекомендуем использовать именно FTP менеджеры для загрузки файлов скрипта на сервер.

- Установите права для записи (CHMOD 777) для папок `/backup/`, `/templates/`, `/uploads/`, `/engine/data/`, `/engine/cache/`.

- Наберите в URL вашего браузера адрес вашего сайта, например `https://website.com/`и следуйте его инструкциям.

Автоматический инсталлятор проверит все необходимые файлы и настроит подключение к базе данных. После завершения установки вы сможете посмотреть работу скрипта на демонстрационной странице `https://website.com/` Для доступа к админпанели необходимо запустить `https://website.com/admin.php`

**Внимание:** чистая установка скрипта приводит к удалению данных ранее установленного скрипта DLE, для обновления установленного скрипта читайте инструкцию по обновлению. После установки или обновления скрипта на сервере обязательно удалите файл **install.php**, иначе будет возможно вновь инициировать процесс инсталляции скрипта, тем самым уничтожив существующую структуру данных.
