# Статические страницы

- **Категория:** Добавление новостей
- **ID темы:** 23
- **Источник:** [https://dle-news.ru/extras/online/?topic=23](https://dle-news.ru/extras/online/?topic=23)

---

Помимо написания динамически изменяемых новостей движок позволяет также написание статических страниц, частое изменение которых не планируется. Для того чтобы создать статическую страницу выберите **"Создать новую страницу"**после этого напишите название страницы, причем только латинскими буквами, потому что оно будет передаваться  в URL сайта для просмотра, также введите описание страницы, это информация только для вас, и последнее создайте шаблон самой страницы, разрешено использование HTML. После создания страницы вы сможете ее просмотреть, изменить, либо удалить.

Адрес статической страницы с использование ЧПУ выглядит так: `https://website.com/название страницы.html`

Адрес статической страницы без ЧПУ выглядит так: `https://website.com/index.php?do=static&page=название страницы`
