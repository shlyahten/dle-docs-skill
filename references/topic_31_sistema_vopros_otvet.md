# Система Вопрос - Ответ

- **Категория:** Добавление новостей
- **ID темы:** 31
- **Источник:** [https://dle-news.ru/extras/online/?topic=31](https://dle-news.ru/extras/online/?topic=31)

---

Система «Вопрос-ответ» позволяет пресечь деятельность спам ботов при регистрации, добавлении новостей или комментариев. Для этого администратор должен задать список вопросов и ответов к ним в специальном разделе. При этом данная система может включаться отдельно для регистрации, добавления новостей, добавления комментариев. Для регистрации посетителей на сайте, система включается в настройках скрипта, а для добавления новостей и комментариев включается в настройках групп, и может включаться только для некоторых групп пользователей. Система «Вопрос-ответ» является полностью автономной и независимой от каптчи на сайте и может использоваться как совместно с каптчей, так и отдельно.

Данная система работает со следующими тегами:

Шаблонные теги `[question]` текст `[/question]` выводят текст, заключенный между ними, только в том случае, если система активирована.

Тег `{question}` выводит вопрос для посетителя.
