**DataLife Engine** позволяет использовать шаблонную систему для вывода новостей, а также для вывода различных модулей. Мы попытались максимально упростить использование шаблонов в движке, для того чтобы их использовать вам не надо обладать никакими знаниями языков программирования, только язык верстки HTML. Однако для более полного и легкого использования шаблонов мы рекомендуем вам внимательно прочитать руководство по работе с шаблонами, чтобы выяснить какие теги используются в шаблонах и для чего они предназначены.

Шаблоном в DLE является папка которая находится в свою очередь в папке `/temlates/`. Файлы находящиеся в папке шаблона, являются файлами одного шаблона.

При помощи шаблона можно управлять визуальным оформлением и панели управления DataLife Engine, для этого в папке своего шаблона вам нужно разместить файл `adminpanel.css`. Он будет автоматически подключен к панели управления после основных стилей и вы можете переназначить любые стили CSS панели управления. Для того чтобы управлять стилями внутри iframe редактора вам необходимо разместить в папке вашего шаблона файл `editor.css`, который будет автоматически подключен внутри iframe редактора после основных стилей и вы можете модифицировать визуальное оформление контента внутри редактора. Чтобы предосмотр при добавлении или редактировании публикаций использовал ваши стили, необходимо разместить в папке шаблона файл `preview.css`. Файлы необходимо размещать именно в папке вашего шаблона, а не в основной `/temlates/`.

Также вы можете подключать один файл шаблона в другой, используя тег `{include file="my_block.tpl"}`данный тег подключает указанный файл `my_block.tpl` в шаблон. Тег призван облегчить структуру шаблона, если используется сложная верстка со множеством тегов. Данный тег действует во всех шаблонных файлах .tpl Подключаемый файл должен находится в папке вашего шаблона или его вложенных папках, если вы хотите подключить файл шаблона, находящийся в другом шаблоне, необходимо использовать полный путь от корня где установлен скрипт, например, `{include file="/templates/mytemplate/my_block.tpl"}`. Также вы можете подлючать при помощи данного тега стили CSS вашего шаблона `{include file="{THEME}/css/styles.css"}`или JS файлы.

Теги в подключаемом шаблоне должны быть такие же, какие допустимы в шаблоне где подключается файл, например если файл **my_block.tpl** подключается в шаблоне **main.tpl**, то и теги в этом файлы будут работать только те которые возможны в **main.tpl**
