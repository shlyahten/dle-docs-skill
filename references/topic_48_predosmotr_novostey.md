# Предосмотр новостей

- **Категория:** Общая информация
- **ID темы:** 48
- **Источник:** [https://dle-news.ru/extras/online/?topic=48](https://dle-news.ru/extras/online/?topic=48)

---

Вывод данного раздела настраивается в файле **preview.tpl**В этом разделе настраиваются шаблоны, предназначенные для предосмотра добавляемых новостей. В данном шаблоне вы можете использовать все теги для краткой и полной новости, а также статических страниц, при этом для разделения просматриваемых частей используются дополнительно теги:

`[short-preview]` текст `[/short-preview]` выводит в тегах текст шаблона предназначенного для просмотра краткой новости

`[full-preview]`текст `[/full-preview]` выводит в тегах текст шаблона предназначенного для просмотра полной новости

`[static-preview]` текст `[/static-preview]` выводит в тегах текст шаблона предназначенного для просмотра статической страницы
