Вывод данного раздела настраивается в файле **tagscloud.tpl**В этом разделе настраиваются шаблоны, которые используются для работы с облаком тегов. В данном блоке показываются все ключевые теги добавленные к новостям.

Возможно использование следующих тегов:

`{tags}` - Используется для вывода всех ключевых тегов, находящихся в базе данных

`{tags limit="100"}` - Используется для вывода 100 самых популярных ключевых тегов, находящихся в базе данных
