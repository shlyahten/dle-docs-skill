# Голосование на сайте

- **Категория:** Общая информация
- **ID темы:** 63
- **Источник:** [https://dle-news.ru/extras/online/?topic=63](https://dle-news.ru/extras/online/?topic=63)

---

Вывод данного раздела настраивается в файле **vote.tpl**В этом разделе настраиваются шаблоны, которые используются для работы с голосованием на сайте.

Возможно использование следующих тегов:

`{title}` - Заголовок опроса

`{list}` - Список вопросов

`{vote_id}` - ID опроса

`{votes}` - Количество голосов

`[votelist]` текст `[/votelist]` - Выводит текст который нужно показывать для еще не голосовавших людей

`[voteresult]` текст `[/voteresult]` - Выводит текст который нужно показывать для уже голосовавших людей
