# RSS трансляция новостей

- **Категория:** Общая информация
- **ID темы:** 69
- **Источник:** [https://dle-news.ru/extras/online/?topic=69](https://dle-news.ru/extras/online/?topic=69)

---

Данный шаблон находится в файле **templates/rss.tpl** и предназначен для настройки вывода RSS потока вашего сайта.

В данном шаблоне вы можете использовать следующие теги:

`[rss]` текст `[/rss]` - Выводят текст заключенный в них, при использовании блока стандартного RSS.

`[dzen]` текст `[/dzen]` - Выводят текст заключенный в них, при использовании блока дзен новостей.

`{title}` - Выводит заголовок новости

`{rsslink}` - Выводит полный URL новости

`{rssauthor}` - Выводят автора новости

`{rssdate}` - Выводят дату новости

`{category}` - Выводят категорию новости

`{short-story}` - Выводят текст краткой новости

`{images}` - Выводит набор картинок для Яндекс новостей

`{full-story}` - Выводит текст полной новости

Также вы можете использовать дополнительно любые теги которые поддерживаются шаблоном вывода краткиких новостей **shortstory.tpl**, однако вам необходимо быть внимательными чтобы не был нарушен стандарт вывода RSS 2.0 который используется для RSS трансляции публикаций.
